MH19 PHOTOWALA — FREE WEBSITE

FILES
- index.html: complete responsive photography website (HTML, CSS, JavaScript in one file)

BEFORE PUBLISHING
1. Open index.html in a text editor.
2. Find this line:
   const WHATSAPP_NUMBER = "919876543210";
3. Replace it with your WhatsApp number using India country code 91, with no +, spaces or dashes.
   Example format: 919876543210
4. Replace the sample gallery image URLs with your own portfolio photos if you want your own work displayed.
   The current photos are sample images from Unsplash and require internet access.

TEST ON YOUR PHONE
- Open index.html in a browser, or upload the file to GitHub Pages.
- The booking form opens WhatsApp with the enquiry details filled in.
- This is a static website: it does not store booking details in a database.

FREE HOSTING WITH GITHUB PAGES
1. Sign in / create an account at https://github.com
2. Create a new public repository named mh19-photowala
3. Upload index.html to the repository root.
4. Go to Settings -> Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for publishing. GitHub will show the website URL in Settings -> Pages.

NOTES
- GitHub Pages hosting can be free for public repositories, subject to GitHub's current terms.
- A custom .com domain usually costs extra.
- Sample photos and text are placeholders. Update them to match your actual services and work.
